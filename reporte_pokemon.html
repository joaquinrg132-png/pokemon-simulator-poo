2. Conceptos de POO Implementados

Concepto Ubicación en el Código Descripción
Constructor (__init__) clases/pokemon.py Inicializa nombre, tipo, ataque, defensa, salud y nivel en 1. Incrementa el contador global.
Destructor (__del__) clases/pokemon.py Se invoca al liberar o borrar el Pokémon. Decrementa el contador global y muestra mensaje de despedida.
Método de Clase (@classmethod) Pokemon.total_pokemons() Accede a la variable de clase _total para reportar cuántos Pokémon siguen activos.
Sobrecarga de Métodos entrenar(*args) Permite entrenar sin argumentos (automático), con 1 argumento (ataque) o 3 (ataque, defensa, salud).
Paso de Parámetros por Referencia atacar(objetivo) Modifica el estado interno del objeto objetivo (salud) al recibirlo como parámetro.
Ámbito de Variables Variables locales / globales Uso de variables locales en cálculos (daño, poder) y globales (pokemons_capturados).
Cálculo de Poder Total poder_total() Retorna (ataque + defensa + salud) * nivel.

"""
=============================================================
  Simulador de Entrenamiento Pokémon
  Módulo: clases/pokemon.py
  Descripción: Define la clase Pokemon con todos los
               conceptos de POO requeridos.
=============================================================
"""

# ─── Variable global de clase (compartida entre todas las instancias) ──────────
# Se actualiza directamente en Pokemon._total para no depender del
# contador mutable desde fuera de la clase.

class Pokemon:
    """
    Representa a un Pokémon con sus estadísticas y comportamientos.

    Atributos de clase
    ------------------
    _total : int
        Número total de Pokémon que han sido creados (variable de clase).

    Atributos de instancia
    ----------------------
    nombre   : str   – Nombre del Pokémon.
    tipo     : str   – Tipo elemental (Fuego, Agua, Eléctrico, etc.).
    nivel    : int   – Nivel actual; inicia en 1.
    ataque   : int   – Puntos de ataque base.
    defensa  : int   – Puntos de defensa base.
    salud    : int   – Puntos de salud actuales.
    salud_max: int   – Puntos de salud máximos (igual a salud inicial).
    """

    # ── Variable de clase ──────────────────────────────────────────────────────
    _total: int = 0  # Cuenta cuántos Pokémon existen actualmente

    # ══════════════════════════════════════════════════════════════════════════
    # CONSTRUCTOR
    # ══════════════════════════════════════════════════════════════════════════
    def __init__(self, nombre: str, tipo: str,
                 ataque: int, defensa: int, salud: int) -> None:
        """
        Inicializa un nuevo Pokémon con los valores dados.

        Parámetros
        ----------
        nombre  : str – Nombre del Pokémon.
        tipo    : str – Tipo elemental.
        ataque  : int – Puntos de ataque base.
        defensa : int – Puntos de defensa base.
        salud   : int – Puntos de salud base.

        Nota: 'nivel' siempre inicia en 1.
        """
        # ── Atributos de instancia (self) ──────────────────────────────────
        self.nombre    = nombre       # Paso de parámetro por valor (str inmutable)
        self.tipo      = tipo
        self.nivel     = 1            # Nivel inicial siempre es 1
        self.ataque    = ataque
        self.defensa   = defensa
        self.salud     = salud
        self.salud_max = salud        # Guardamos la salud máxima para referencia

        # ── Actualizar contador de clase ───────────────────────────────────
        Pokemon._total += 1

        # ── Mensaje de creación ────────────────────────────────────────────
        print(f"\n  ✨ ¡{self.nombre} ({self.tipo}) ha sido capturado! "
              f"[Nivel {self.nivel}]")

    # ══════════════════════════════════════════════════════════════════════════
    # DESTRUCTOR
    # ══════════════════════════════════════════════════════════════════════════
    def __del__(self) -> None:
        """
        Se ejecuta cuando el objeto es eliminado de memoria.
        Muestra un mensaje de despedida y decrementa el contador.
        """
        # Protección ante errores durante el apagado del intérprete
        try:
            Pokemon._total -= 1
            print(f"\n  🕊️  {self.nombre} ha sido liberado ✨")
        except Exception:
            pass

    # ══════════════════════════════════════════════════════════════════════════
    # MÉTODOS DE INSTANCIA
    # ══════════════════════════════════════════════════════════════════════════

    def entrenar(self, *args) -> None:
        """
        Entrena al Pokémon aumentando su nivel y sus estadísticas.

        Sobrecarga mediante *args
        ─────────────────────────
        Sin argumentos  → aumenta ataque, defensa y salud con valores
                          predeterminados escalados por nivel.
        1 argumento     → sólo mejora el ataque en la cantidad indicada.
        2 argumentos    → mejora ataque y defensa en las cantidades indicadas.
        3+ argumentos   → mejora ataque, defensa y salud con los valores dados.

        Parámetros
        ----------
        *args : int (opcional) – Cantidades de mejora para cada estadística.

        Variables locales
        -----------------
        bonus_ataque, bonus_defensa, bonus_salud : int
            Incrementos que se aplicarán en esta sesión de entrenamiento.
        """
        # ── Variables locales (ámbito de función) ──────────────────────────
        bonus_ataque  = 0
        bonus_defensa = 0
        bonus_salud   = 0

        if len(args) == 0:
            # Sin argumentos: mejora automática escalada al nivel actual
            bonus_ataque  = 5 + self.nivel * 2
            bonus_defensa = 3 + self.nivel
            bonus_salud   = 10 + self.nivel * 3

        elif len(args) == 1:
            # 1 argumento: sólo ataque
            bonus_ataque = int(args[0])

        elif len(args) == 2:
            # 2 argumentos: ataque y defensa
            bonus_ataque  = int(args[0])
            bonus_defensa = int(args[1])

        else:
            # 3 o más argumentos: ataque, defensa y salud
            bonus_ataque  = int(args[0])
            bonus_defensa = int(args[1])
            bonus_salud   = int(args[2])

        # ── Subir nivel ────────────────────────────────────────────────────
        self.nivel    += 1

        # ── Aplicar bonificaciones (modificación por referencia del objeto) ──
        self.ataque   += bonus_ataque
        self.defensa  += bonus_defensa
        self.salud    += bonus_salud
        self.salud_max = self.salud    # La salud máxima crece con el entrenamiento

        # ── Mostrar resultado ──────────────────────────────────────────────
        print(f"\n  💪 ¡{self.nombre} ha entrenado duro!")
        print(f"     Nivel     : {self.nivel - 1} → {self.nivel}")
        if bonus_ataque  > 0:
            print(f"     Ataque    : +{bonus_ataque}")
        if bonus_defensa > 0:
            print(f"     Defensa   : +{bonus_defensa}")
        if bonus_salud   > 0:
            print(f"     Salud     : +{bonus_salud}")

    # ──────────────────────────────────────────────────────────────────────────
    def mostrar_info(self) -> None:
        """
        Muestra todos los datos del Pokémon en un formato legible.
        Accede a los atributos usando self.
        """
        barra = self._barra_salud()
        print(f"""
  ╔══════════════════════════════════════╗
  ║  🐾  {self.nombre:<33}║
  ╠══════════════════════════════════════╣
  ║  Tipo     : {self.tipo:<27}║
  ║  Nivel    : {self.nivel:<27}║
  ║  Ataque   : {self.ataque:<27}║
  ║  Defensa  : {self.defensa:<27}║
  ║  Salud    : {self.salud}/{self.salud_max:<21}║
  ║  HP       : {barra:<27}║
  ╚══════════════════════════════════════╝""")

    # ──────────────────────────────────────────────────────────────────────────
    def atacar(self, objetivo: "Pokemon") -> None:
        """
        Simula un ataque a otro Pokémon.
        El daño se calcula con:  daño = max(1, self.ataque - objetivo.defensa // 2)

        Parámetros
        ----------
        objetivo : Pokemon – El Pokémon que recibirá el daño.
                              Se pasa por referencia (objeto mutable),
                              por lo que sus atributos son modificados.

        Variables locales
        -----------------
        daño    : int  – Daño calculado para este ataque.
        critico : bool – Indica si el ataque fue crítico (1 en 5).
        """
        import random  # ámbito local de import

        # ── Variables locales ──────────────────────────────────────────────
        critico = random.randint(1, 5) == 1
        daño    = max(1, self.ataque - objetivo.defensa // 2)

        if critico:
            daño = int(daño * 1.5)

        # ── Modificar la salud del objetivo (paso por referencia) ──────────
        objetivo.salud = max(0, objetivo.salud - daño)

        # ── Mostrar resultado ──────────────────────────────────────────────
        tipo_ataque = "¡CRÍTICO! 💥" if critico else "⚔️"
        print(f"\n  {tipo_ataque}  {self.nombre} ataca a {objetivo.nombre}!")
        print(f"     Daño causado  : {daño}")
        print(f"     Salud restante: {objetivo.salud}/{objetivo.salud_max}")

        if objetivo.salud == 0:
            print(f"     💀 ¡{objetivo.nombre} ha sido derrotado!")

    # ══════════════════════════════════════════════════════════════════════════
    # MÉTODO DE CLASE
    # ══════════════════════════════════════════════════════════════════════════

    @classmethod
    def total_pokemons(cls) -> None:
        """
        Muestra cuántos Pokémon han sido creados y siguen activos.
        Accede a la variable de clase a través de 'cls'.
        """
        print(f"\n  🧮 Pokémon activos en el sistema: {cls._total}")

    # ══════════════════════════════════════════════════════════════════════════
    # MÉTODO DE PODER TOTAL
    # ══════════════════════════════════════════════════════════════════════════

    def poder_total(self) -> int:
        """
        Calcula y retorna el poder total del Pokémon.
        Fórmula: (ataque + defensa + salud) * nivel

        Retorno
        -------
        int – Puntuación de poder total.
        """
        # Variable local para el cálculo
        poder = (self.ataque + self.defensa + self.salud) * self.nivel
        return poder

    # ══════════════════════════════════════════════════════════════════════════
    # MÉTODO PRIVADO AUXILIAR
    # ══════════════════════════════════════════════════════════════════════════

    def _barra_salud(self) -> str:
        """
        Genera una barra de salud visual de 10 caracteres.

        Retorno
        -------
        str – Barra de salud con emojis.
        """
        if self.salud_max == 0:
            return "░░░░░░░░░░"
        # Variable local: porcentaje de salud
        porcentaje = self.salud / self.salud_max
        llenas     = int(porcentaje * 10)
        vacias     = 10 - llenas
        return "█" * llenas + "░" * vacias

    # ──────────────────────────────────────────────────────────────────────────
    def __str__(self) -> str:
        """Representación legible del Pokémon (usada en print())."""
        return (f"{self.nombre} [{self.tipo}] "
                f"Lv.{self.nivel} | "
                f"ATK:{self.ataque} DEF:{self.defensa} HP:{self.salud}")

    def __repr__(self) -> str:
        """Representación técnica del Pokémon."""
        return (f"Pokemon(nombre='{self.nombre}', tipo='{self.tipo}', "
                f"nivel={self.nivel}, ataque={self.ataque}, "
                f"defensa={self.defensa}, salud={self.salud})")

def pedir_entero(mensaje: str, minimo: int = 1, maximo: int = 999) -> int:
    """
    Solicita un número entero al usuario dentro de un rango.

    Parámetros (paso por valor)
    ---------------------------
    mensaje : str – Texto de solicitud.
    minimo  : int – Valor mínimo aceptado.
    maximo  : int – Valor máximo aceptado.

    Variable local
    --------------
    valor : int – Valor ingresado por el usuario.
    """
    while True:
        try:
            valor = int(input(f"  {mensaje}: ").strip())  # variable local
            if minimo <= valor <= maximo:
                return valor
            print(f"  ⚠️  Ingresa un número entre {minimo} y {maximo}.")
        except ValueError:
            print("  ⚠️  Por favor ingresa un número válido.")


def seleccionar_pokemon(mensaje: str = "Selecciona un Pokémon") -> Pokemon | None:
    """
    Muestra la lista de Pokémon capturados y permite seleccionar uno.

    Parámetros
    ----------
    mensaje : str – Texto de encabezado.

    Retorno
    -------
    Pokemon | None – El Pokémon seleccionado, o None si no hay ninguno.
    """
    # Acceso a variable global
    global pokemons_capturados

    if not pokemons_capturados:
        print("\n  ⚠️  No tienes Pokémon capturados todavía.")
        return None

    print(f"\n  {mensaje}:")
    for indice, poke in enumerate(pokemons_capturados, start=1):
        print(f"    {indice}. {poke}")

    opcion = pedir_entero("Número del Pokémon", 1, len(pokemons_capturados))
    return pokemons_capturados[opcion - 1]  # Acceso por referencia al objeto

# OPCIÓN 1: CAPTURAR POKÉMON

def capturar_pokemon() -> None:
    """
    Permite crear un nuevo Pokémon (predefinido o personalizado)
    y lo agrega a la lista global.

    Variables locales: nombre, tipo, ataque, defensa, salud, nuevo_pokemon.
    Variable global modificada: pokemons_capturados.
    """
    global pokemons_capturados  # Declaramos uso de variable global

    print("\n  ══ CAPTURAR POKÉMON ══")
    print("\n  ¿Cómo quieres capturar tu Pokémon?")
    print("    A. Elegir un Pokémon predefinido")
    print("    B. Crear un Pokémon personalizado")

    modo = input("\n  Opción (A/B): ").strip().upper()

    if modo == "A":
        # ── Pokémon predefinido ────────────────────────────────────────────
        print("\n  Pokémon disponibles:")
        for clave, datos in POKEMONS_PREDEFINIDOS.items():
            print(f"    {clave}. {datos[0]:10} | Tipo: {datos[1]:10} | "
                  f"ATK:{datos[2]} DEF:{datos[3]} HP:{datos[4]}")

        eleccion = input("\n  Elige un número (1-8): ").strip()
        if eleccion not in POKEMONS_PREDEFINIDOS:
            print("  ⚠️  Opción inválida.")
            return

        datos = POKEMONS_PREDEFINIDOS[eleccion]
        # Variables locales con los datos del Pokémon predefinido
        nombre, tipo, ataque, defensa, salud = datos

    elif modo == "B":
        # ── Pokémon personalizado ──────────────────────────────────────────
        nombre  = input("\n  Nombre del Pokémon : ").strip()
        if not nombre:
            print("  ⚠️  El nombre no puede estar vacío.")
            return

        print(f"\n  Tipos disponibles: {', '.join(TIPOS_DISPONIBLES)}")
        tipo    = input("  Tipo              : ").strip().capitalize()

        print("\n  Estadísticas (valores entre 10 y 200):")
        ataque  = pedir_entero("Ataque ", 10, 200)
        defensa = pedir_entero("Defensa", 10, 200)
        salud   = pedir_entero("Salud  ", 10, 200)
    else:
        print("  ⚠️  Opción inválida.")
        return

    # ── Crear la instancia (se pasan parámetros por valor) ────────────────
    nuevo_pokemon = Pokemon(nombre, tipo, ataque, defensa, salud)

    # ── Agregar a la lista global (paso por referencia del objeto) ────────
    pokemons_capturados.append(nuevo_pokemon)

# OPCIÓN 2: ENTRENAR UN POKÉMON

def entrenar_pokemon() -> None:
    """
    Permite elegir cómo entrenar un Pokémon seleccionado,
    demostrando la sobrecarga de métodos con *args.
    """
    print("\n  ══ ENTRENAR POKÉMON ══")
    pokemon = seleccionar_pokemon("¿Qué Pokémon quieres entrenar?")
    if pokemon is None:
        return

    print(f"\n  Entrenando a {pokemon.nombre}...")
    print("  ¿Cómo quieres entrenar?")
    print("    1. Entrenamiento automático (sin argumentos)")
    print("    2. Mejorar sólo Ataque (1 argumento)")
    print("    3. Mejorar Ataque y Defensa (2 argumentos)")
    print("    4. Mejorar Ataque, Defensa y Salud (3 argumentos)")

    modo = pedir_entero("Modo de entrenamiento", 1, 4)

    # ── Demostramos sobrecarga de métodos según la elección ────────────────
    if modo == 1:
        pokemon.entrenar()                  # Sin argumentos
    elif modo == 2:
        val_atk = pedir_entero("Puntos de Ataque a ganar", 1, 100)
        pokemon.entrenar(val_atk)           # 1 argumento
    elif modo == 3:
        val_atk = pedir_entero("Puntos de Ataque a ganar ", 1, 100)
        val_def = pedir_entero("Puntos de Defensa a ganar", 1, 100)
        pokemon.entrenar(val_atk, val_def)  # 2 argumentos
    else:
        val_atk = pedir_entero("Puntos de Ataque a ganar ", 1, 100)
        val_def = pedir_entero("Puntos de Defensa a ganar", 1, 100)
        val_sal = pedir_entero("Puntos de Salud a ganar  ", 1, 200)
        pokemon.entrenar(val_atk, val_def, val_sal)  # 3 argumentos

    # Mostrar poder total después del entrenamiento
    poder = pokemon.poder_total()  # variable local
    print(f"\n  ⭐ Poder total de {pokemon.nombre}: {poder} pts")


# ══════════════════════════════════════════════════════════════════════════════
# OPCIÓN 3: VER INFORMACIÓN
# ══════════════════════════════════════════════════════════════════════════════

def ver_informacion() -> None:
    """
    Muestra la información de todos los Pokémon o de uno seleccionado.
    Accede a la variable global pokemons_capturados.
    """
    global pokemons_capturados

    if not pokemons_capturados:
        print("\n  ⚠️  No tienes Pokémon capturados todavía.")
        return

    print("\n  ══ INFORMACIÓN DE POKÉMON ══")
    print("    1. Ver todos")
    print("    2. Ver uno específico")
    opcion = pedir_entero("Opción", 1, 2)

    if opcion == 1:
        for poke in pokemons_capturados:  # Paso por referencia (iteración)
            poke.mostrar_info()
            print(f"  ⭐ Poder total: {poke.poder_total()} pts")
    else:
        pokemon = seleccionar_pokemon("¿De qué Pokémon quieres ver información?")
        if pokemon:
            pokemon.mostrar_info()
            print(f"  ⭐ Poder total: {pokemon.poder_total()} pts")


# ══════════════════════════════════════════════════════════════════════════════
# OPCIÓN 4: TOTAL DE POKÉMON (método de clase)
# ══════════════════════════════════════════════════════════════════════════════

def mostrar_total() -> None:
    """Llama al método de clase total_pokemons()."""
    Pokemon.total_pokemons()  # Llamada a método de clase (sin instancia)
    print(f"  📋 En tu equipo: {len(pokemons_capturados)} Pokémon")


# ══════════════════════════════════════════════════════════════════════════════
# OPCIÓN 5: SIMULAR BATALLA
# ══════════════════════════════════════════════════════════════════════════════

def simular_batalla() -> None:
    """
    Simula una batalla entre dos Pokémon del equipo.
    Demuestra el paso de objetos por referencia en atacar().
    """
    global pokemons_capturados

    if len(pokemons_capturados) < 2:
        print("\n  ⚠️  Necesitas al menos 2 Pokémon para batallar.")
        return

    print("\n  ══ SIMULAR BATALLA ══")
    print("\n  Selecciona el Pokémon atacante:")
    atacante = seleccionar_pokemon("Atacante")
    if atacante is None:
        return

    print("\n  Selecciona el Pokémon defensor:")
    defensor = seleccionar_pokemon("Defensor")
    if defensor is None:
        return

    if atacante is defensor:
        print("  ⚠️  Un Pokémon no puede atacarse a sí mismo.")
        return

    print(f"\n  🥊 ¡{atacante.nombre} VS {defensor.nombre}!")
    print("  " + "─" * 40)

    # ── El objeto defensor se pasa por referencia; su salud es modificada ──
    atacante.atacar(defensor)


# ══════════════════════════════════════════════════════════════════════════════
# OPCIÓN 6: LIBERAR UN POKÉMON (destructor)
# ══════════════════════════════════════════════════════════════════════════════

def liberar_pokemon() -> None:
    """
    Elimina un Pokémon de la lista global.
    Al eliminar la última referencia, Python llama automáticamente a __del__.

    Variable global modificada: pokemons_capturados.
    Variable local: indice, confirmacion.
    """
    global pokemons_capturados

    print("\n  ══ LIBERAR POKÉMON ══")

    if not pokemons_capturados:
        print("\n  ⚠️  No tienes Pokémon para liberar.")
        return

    print("\n  Pokémon disponibles:")
    for indice, poke in enumerate(pokemons_capturados, start=1):  # indice: var local
        print(f"    {indice}. {poke}")

    num = pedir_entero("Número del Pokémon a liberar", 1, len(pokemons_capturados))
    pokemon = pokemons_capturados[num - 1]

    confirmacion = input(  # variable local
        f"\n  ¿Seguro que quieres liberar a {pokemon.nombre}? (s/n): "
    ).strip().lower()

    if confirmacion == "s":
        # Remover de la lista y eliminar la referencia → activa __del__
        pokemons_capturados.pop(num - 1)
        del pokemon  # Elimina la referencia → llama a __del__
    else:
        print(f"\n  {pokemon.nombre} se queda contigo. 🤝")

# FUNCIÓN PRINCIPAL
# ══════════════════════════════════════════════════════════════════════════════

def main() -> None:
    """
    Función principal que controla el ciclo del menú.
    Usa la variable global pokemons_capturados a través de las funciones.
    """
    # ── Tabla de despacho: mapea opciones a funciones ─────────────────────
    acciones = {
        "1": capturar_pokemon,
        "2": entrenar_pokemon,
        "3": ver_informacion,
        "4": mostrar_total,
        "5": simular_batalla,
        "6": liberar_pokemon,
    }

    mostrar_banner()

    # ── Ciclo principal del menú ───────────────────────────────────────────
    while True:
        mostrar_menu_principal()
        opcion = input("\n  Elige una opción (1-7): ").strip()  # variable local

        if opcion == "7":
            print("\n  👋 ¡Hasta pronto, Entrenador! ¡Atrapa a todos! 🎯\n")
            break
        elif opcion in acciones:
            acciones[opcion]()  # Llamada a la función correspondiente
        else:
            print("  ⚠️  Opción no válida. Elige entre 1 y 7.")

        input("\n  Presiona ENTER para continuar...")
        limpiar_pantalla()
        mostrar_banner()


# ══════════════════════════════════════════════════════════════════════════════
# PUNTO DE ENTRADA
# ══════════════════════════════════════════════════════════════════════════════

if __name__ == "__main__":
    main()
